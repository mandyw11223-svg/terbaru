# Petualangan Lebah

Game edukasi interaktif tentang bagian bunga dan proses penyerbukan. Situs ini
dibuat sebagai halaman statis dan dapat dibuka langsung di Chrome maupun
peramban modern lainnya.

## Publikasi

Workflow GitHub Pages menerbitkan situs secara otomatis setiap kali perubahan
masuk ke branch `main`. Setelah workflow pertama berhasil, situs tersedia di:

https://mandyw11223-svg.github.io/terbaru/

Repository harus dapat diakses publik agar situsnya dapat dibuka oleh semua
orang. GitHub Pages diatur otomatis oleh workflow saat deployment pertama.
